# 真实项目全流程质量评分

按实际证据评分，测试数量、输出篇幅和与参考方案同名均不加分。

1. 重构是否完成任务要求的职责拆分，保持接口和语义；空补丁、注释修改或仅改名不能代表任务完成。
2. 测试是否编译/调用两侧各自真实实现；辅助代码是否只提供调用、观测及必要依赖，未复制被测算法。
3. 验证方式是否适合目标，是否识别真实依赖与已有覆盖缺口；局部程序、已有测试、真实产物和组合方案都可以正确。
4. 核心边界、错误副作用、状态序列与资源所有权是否得到有效检查；避免只断言进程退出 0。
5. 依赖替身是否遵守公开 ABI/协议，能够控制部分成功、临时失败、超时和清理；不能直接替换被测函数。
6. 运行是否稳定、可复现并正常回收；不固定 PID、耗时、端口或合法随机顺序，不把跳过和零测试算通过。
   除公开契约明确要求的资源释放外，不把分段读写的确切次数、内部时钟查询次数或某个合法剩余预算序列固定成断言。

程序裁决与独立复核是必要证据，但不足以自动证明重构质量。结合保存的工作流、辅助材料、候选补丁及
该场景 reference.md 解释得分和缺口。评分范围 [0,1]，任一严重问题应明确说明：复制/绕过真实实现、
将缺失依赖当作成功、无实质性重构、测试从未执行。没有实际运行证据时不能以推测补齐。
