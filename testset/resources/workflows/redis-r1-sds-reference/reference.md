# 字符串参数拆分

目标：`src/sds.c`。任务与协议保持要求见任务简报。

参考检查见 `resources/judge/`；固定对照如下。

- equivalent：提取共享的引号结束条件，期望 ACCEPTED。
- drop-nul：丢弃转义产生的 NUL 字节，期望 REJECTED。
- allow-quote-tail：错误接受闭合引号后的非空白字符，期望 REJECTED。

复核生成方案是否调用当前侧真实实现，是否保持外部接口与资源所有权，是否有效执行而非只声明成功。测试方式无需与参考相同。实质性的辅助函数提取和任务完成度需要结合候选补丁人工或模型评分，单纯改名不能作为任务完成。

## 行为与质量复核要点

测试对象是当前侧真实 `sdssplitargs`，局部 C 调用程序即可；应保留真实 SDS 和分配器。
重点是空输入/空 token、单双引号的不同转义、字节长度（含 NUL/FF）、闭合引号后必须结束或空白、非法输入返回 NULL 并把 argc 清零。
不要用 strlen 代替二进制结果比较，不要把解析算法复制到测试中，也不要把正常空结果当成未执行。参考共有 15 项。
