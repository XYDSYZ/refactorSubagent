## 行为与质量复核要点

测试对象是 SET 共用选项解析及可观察命令结果。参考使用当前侧真实服务器，组合上游字符串 Tcl 单元和 13 项新检查。
应覆盖 NX/XX 的创建/拒绝与原值、GET 与 XX 组合的返回旧值、重复 GET、KEEPTTL 和错误时值/TTL不变，选项互斥及错误类型。
GET 错误对照只让 GET 与 XX 组合丢失标志，避免破坏后续上游测试的准备数据；它应由 xx-get-old-value 检出。
服务器必须独立启动和回收，不能共享两侧数据库。上游需真正完成、无内部超时且目标测试非空。
