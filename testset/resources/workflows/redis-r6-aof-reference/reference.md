# AOF 清单与恢复

目标：`src/aof.c`。任务与协议保持要求见任务简报。

参考检查见 `resources/judge/`；固定对照如下。

- equivalent：提取文件名表示生成，期望 ACCEPTED。
- unescaped-filename：清单文件名不再转义，期望 REJECTED。
- wrong-end-offset：结束偏移被写成开始偏移，期望 REJECTED。

复核生成方案是否调用当前侧真实实现，是否保持外部接口与资源所有权，是否有效执行而非只声明成功。测试方式无需与参考相同。实质性的辅助函数提取和任务完成度需要结合候选补丁人工或模型评分，单纯改名不能作为任务完成。

## 行为与质量复核要点

目标是当前侧真实 aofInfoFormat；参考以 5 项局部格式检查加真实服务器生命周期，共 12 项。
格式检查比较普通/空格/引号文件名、startoffset=0、不同 start/endoffset；必须调用真实格式化函数，不能复制序列化算法。
真实服务器写值、hash 与空串后正常关闭，在真实 AOF 中加入第二份增量，再重启核对最新值和其他数据恢复，检查损坏 manifest 明确拒绝。
两侧各自文件目录，关闭和异常回收完整，不用历史运行或仅伪造文本替代恢复验证。
